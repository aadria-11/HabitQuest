## Questions & Troubleshooting

### Q: Why increase cache TTL to 5000ms?
**A:** Session tokens remain valid much longer (days/weeks). 5s captures bursts of API calls within milliseconds, balancing effectiveness and freshness.

### Q: Could the race condition happen with this fix?
**A:** No. Database constraint now enforces uniqueness at write time. Even concurrent inserts will trigger constraint violation on the duplicate.

### Q: Why use refs instead of callbacks in dependencies?
**A:** Refs prevent listener re-attachment while keeping callbacks up-to-date. Simpler than memoization and avoids parent re-render triggers.

### Q: Is the performance improvement measurable?
**A:** Yes. Monitor these metrics:
- `getSession()` call frequency (should drop 10x)
- API latency (should decrease ~50ms per call)
- Memory usage over time (should stabilize)
